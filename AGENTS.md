# Agent Instructions

This repository includes project skills for PocketDaemon installation and
deployment work:

- Codex: `.agents/skills/pocketdaemon-install/SKILL.md`
- Claude Code: `.claude/skills/pocketdaemon-install/SKILL.md`
- Cursor: `.cursor/skills/pocketdaemon-install/SKILL.md`

Use that skill when asked to build, install, update, configure, verify, back up,
restore, root a device for, or troubleshoot PocketDaemon. Keep the three skill
copies in sync when changing the install workflow.
